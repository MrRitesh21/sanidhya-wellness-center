## 4. Premium Smooth Motion Graphics

Use Framer Motion or Motion for React, depending on the project setup.

Implement:
- Smooth page entrance transitions.
- Scroll-triggered fade and reveal animations.
- Staggered section and card appearances.
- Gentle parallax on selected background imagery.
- Subtle botanical line animations.
- Soft floating decorative elements.
- Smooth button hover and tap feedback.
- Elegant mobile navigation transitions.
- Refined image reveal effects.
- Smooth accordion animations for FAQs.
- A polished appointment modal or booking section transition.
- Subtle header transformations on scroll.

Motion rules:
- Use natural easing and restrained durations.
- Prefer opacity and transform animations for performance.
- Avoid constant distracting movement, aggressive zooms, and excessive bouncing.
- Respect `prefers-reduced-motion`.
- Keep page content accessible immediately.
- Ensure animations remain smooth on mid-range Android phones.
- Never sacrifice loading speed for visual effects.
